# algorithm-study
알고리즘 공부 기록입니다.

## 📌 목표
- 알고리즘 유형별 개념 정리
- 코딩 테스트 대비
- 기술 면접에서 설명 가능한 수준의 이해

## 📂 분류
- 수학
- 정렬
- 문자열
- 해시
- 재귀 / 완전탐색
- 그리디
- 리스트
- 스택 / 큐
- 트리
- 그래프
- 동적 계획법
- 이분 탐색
- 투 포인터

## 🖋️️ 각 폴더에는
**개념**, **사용 상황**, **구현 포인트**, **시간복잡도**, **실수 포인트**, **구현 코드**, **대표 문제**를 포함한다.
