# 깊이우선탐색 (DFS)

## 개념
- 한 방향으로 최대한 깊게 탐색한 뒤, 더 이상 이동할 수 없으면 이전 정점으로 돌아와 다른 경로를 탐색하는 알고리즘
- **재귀 호출** 또는 **Stack**을 사용하여 구현
- 그래프의 모든 정점이나 경로를 탐색할 때 사용
- 재귀 호출은 내부적으로 Call Stack을 사용하므로 DFS와 같은 방식으로 동작

## 사용 상황
- 그래프의 모든 정점을 탐색해야 할 때
- 연결 요소의 개수를 구할 때
- 두 정점이 연결되어 있는지 확인할 때
- 특정 경로가 존재하는지 확인할 때
- 그래프의 사이클을 탐지할 때
- 트리를 전위·중위·후위 순회할 때
- 모든 경로나 경우의 수를 탐색할 때
- 순열, 조합, 부분집합을 생성할 때
- 백트래킹을 이용해 조건을 만족하는 경우를 탐색할 때

### 문제에서 다음과 같은 표현이 나오면 DFS를 고려한다.
- 모든 경우를 탐색
- 연결되어 있는가
- 몇 개의 영역으로 나뉘는가
- 가능한 경로가 존재하는가
- 조건을 만족하는 모든 조합
- 한 방향으로 끝까지 탐색
- ❌ 일반 DFS가 적합하지 않은 경우
    - 가중치가 없는 그래프의 최단 거리
    - 최소 이동 횟수
    - 가장 가까운 대상 탐색
    - 재귀 깊이가 매우 큰 그래프

## 구현 포인트
#### 1. 현재 정점 방문 처리
- 현재 정점에 도착하면 바로 방문 처리
- 양방향 그래프에서 같은 정점을 반복해서 탐색하는 것을 방지

```java
visited[now] = true;
````

#### 2. 인접 정점 탐색
- 현재 정점과 연결된 모든 정점을 확인
- 아직 방문하지 않은 정점으로 이동

```java
for (int next : graph[now]) {
    if (visited[next]) continue;

    dfs(next);
}
```

#### 3. 재귀 호출로 깊이 이동
- 현재 정점에서 방문하지 않은 인접 정점으로 이동
- 재귀 호출이 끝나면 이전 정점으로 되돌아옴

```java
dfs(next);
```

#### 4. 연결되지 않은 그래프 전체 탐색
- dfs(1)만 호출하면 1번 정점과 연결된 정점만 탐색
- 그래프 전체를 탐색하려면 모든 정점을 확인해야 함

```java
for (int i = 1; i <= V; i++) {
    if (visited[i]) continue;

    dfs(i);
}
```

> **왜 재귀 호출로 DFS가 가능할까?**
>
> - 재귀 호출은 가장 마지막에 호출한 메서드부터 종료되는 LIFO 구조
> - 현재 경로를 끝까지 탐색한 후 이전 호출로 복귀
> - Stack과 동일한 방식으로 깊이 우선 탐색 가능

## 시간복잡도
- 인접리스트: **O(V+E)**
- 인접 행렬: **O(V²)**

## 실수 포인트
- 방문 처리를 하지 않음 &rarr; 양방향 그래프에서 같은 정점을 반복 방문하며 무한 재귀가 발생할 수 있음
- 현재 정점을 너무 늦게 방문 처리 &rarr; 일반적으로 DFS에 들어오자마자 방문 처리
- 재귀 깊이가 너무 깊음 &rarr; **StackOverflowError**가 발생할 수 있음
