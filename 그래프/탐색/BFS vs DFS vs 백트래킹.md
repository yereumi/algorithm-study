# BFS vs DFS vs 백트래킹

| 구분 | BFS | DFS | 백트래킹 |
|------|-----|-----|----------|
| 목적 | 가까운 정점부터 탐색, 최단 거리 | 모든 정점·경로 탐색 | 조건을 만족하는 모든 경우 탐색 |
| 탐색 방식 | 너비 우선 | 깊이 우선 | DFS + 상태 복원 + 가지치기 |
| 핵심 자료구조 | Queue | 재귀 또는 Stack | 재귀 |
| 방문 처리 | Queue에 넣을 때 | 정점 방문 시 | 선택 후, 탐색 종료 시 복원 |
| 상태 복원 | 필요 없음 | 필요 없음 | **필수** |
| 가지치기 | 없음 | 없음 | **핵심 요소** |
| 최단 거리 | 동일 가중치에서 보장 | 보장하지 않음 | 보장하지 않음 |
| 시간복잡도 | **O(V + E)** | **O(V + E)** | 경우의 수에 따라 다름 |
| 대표 문제 | 미로 탐색, 최단 거리 | 연결 요소, 사이클 탐색 | 순열, 조합, N-Queen, 스도쿠 |
| 대표 키워드 | 최소 이동, 가장 가까운 | 연결 여부, 모든 경로 | 모든 경우, 조건 만족 |

## 핵심 차이 한 줄 요약
- **BFS**: "가까운 곳부터 차례대로 탐색하자."
- **DFS**: "한 방향으로 끝까지 탐색한 뒤 돌아오자."
- **백트래킹**: "가능성이 없는 경로는 중간에 버리고 탐색하자."

## 선택 기준 정리
- **최단 거리, 최소 이동 횟수** &rarr; BFS
- **그래프 전체 탐색, 연결 여부 확인** &rarr; DFS
- **모든 경우를 탐색하면서 조건을 만족하는 해를 찾아야 함** &rarr; 백트래킹
- **불가능한 경우를 미리 제거할 수 있다** &rarr; 백트래킹이 매우 유리
