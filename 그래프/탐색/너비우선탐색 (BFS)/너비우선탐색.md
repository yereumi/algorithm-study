# 너비우선탐색 (BFS)

## 개념
- 시작 정점에서 가까운 정점부터 순서대로 탐색하는 알고리즘
- 현재 정점과 인접한 정점을 모두 탐색한 뒤, 다음 깊이의 정점으로 이동
- **Queue**를 사용하여 구현
- 가중치가 없거나 모든 간선의 가중치가 동일한 그래프에서 최단 거리를 구할 수 있음

## 사용 상황
- 그래프의 모든 정점을 탐색해야 할 때
- 가중치가 없는 그래프의 최단 거리를 구할 때
- 모든 간선의 가중치가 동일할 때
- 최소 이동 횟수를 구할 때
- 시작점에서 가장 가까운 대상을 찾을 때
- 트리를 레벨 단위로 탐색할 때
- 여러 시작점에서 동시에 탐색해야 할 때

### 문제에서 다음과 같은 표현이 나오면 BFS를 고려한다.
- 최소 횟수
- 최소 이동
- 가장 빠른 시간
- 가장 가까운 위치
- 몇 단계 만에 도달 가능한가
- ❌ 일반 BFS 사용 불가
    - 간선마다 가중치가 다른 최단 거리 문제
    - 음수 가중치가 존재하는 문제
    - 모든 경우의 수나 경로를 탐색해야 하는 문제

| 간선 조건 | 알고리즘 |
|:------:|:------:|
| 가중치 없음 or 모든 가중치 동일 | BFS |
| 가중치가 0 또는 1 | 0-1 BFS |
| 음수가 없는 서로 다른 가중치 | 다익스트라 |
| 음수 가중치 존재 | 벨만-포드 |

## 구현 포인트
#### 1. 시작 정점을 Queue에 삽입
- 탐색을 시작할 정점을 Queue에 삽입
- 시작 정점도 반드시 방문 처리

```java
Queue<Integer> queue = new ArrayDeque<>();

visited[start] = true;
queue.offer(start);
````

#### 2. Queue에서 정점 꺼내기
- Queue의 가장 앞에 있는 정점을 꺼냄
- 먼저 들어간 정점부터 처리하는 **FIFO 구조**

```java
int cur = queue.poll();
```

#### 3. 인접 정점 탐색
- 현재 정점과 연결된 모든 정점을 확인
- 이미 방문한 정점은 건너뜀

```java
for (int next : graph[cur]) {
    if (visited[next]) continue;
}
```

#### 4. Queue에 넣을 때 방문 처리
- 방문하지 않은 정점을 Queue에 삽입
- 같은 정점이 Queue에 여러 번 들어가는 것을 방지하기 위해 삽입 시점에 방문 처리

```java
visited[next] = true;
queue.offer(next);
```

#### 5. Queue가 빌 때까지 반복
- Queue가 비면 시작 정점에서 도달할 수 있는 모든 정점의 탐색이 끝난 것

```java
while (!queue.isEmpty()) {
    int cur = queue.poll();

    for (int next : graph[now]) {
        if (visited[next]) continue;

        visited[next] = true;
        queue.offer(next);
    }
}
```

> **왜 Queue를 사용할까?**
>
> - 먼저 발견한 정점을 먼저 탐색해야 함
> - 시작 정점에서 가까운 순서대로 탐색 가능
> - Queue의 FIFO 구조를 이용하면 같은 깊이의 정점을 먼저 처리할 수 있음

## 시간복잡도
- 인접 행렬: **O(V²)**
- 2차원 배열: **O(N*M)**

## 실수 포인트
- Queue에 넣을 때 방문 처리하지 않음 &rarr; 같은 정점이 Queue에 여러 번 들어갈 수 있음
