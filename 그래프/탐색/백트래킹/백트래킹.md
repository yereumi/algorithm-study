# 백트래킹 (Backtracking)

## 개념
- DFS를 기반으로 가능한 선택지를 탐색하는 문제 해결 기법
- 현재 선택으로 정답을 만들 수 없다고 판단되면 더 이상 탐색하지 않고 이전 상태로 돌아감
- 재귀 호출 이후 선택 상태를 원래대로 복원
- 불가능한 경로를 미리 제거하는 **가지치기(Pruning)**를 사용

## 사용 상황
- 순열
- 조합
- 부분집합
- N-Queen
- 스도쿠
- 암호 만들기
- 연산자 끼워 넣기
- 조건을 만족하는 모든 경우 탐색
- 완전탐색의 탐색량을 가지치기로 줄여야 할 때
- ❌ 백트래킹이 적합하지 않은 경우
    - 하나의 최단 거리만 구하는 문제
    - 단순 연결 여부만 확인하면 되는 문제
    - 경우의 수가 지나치게 많아 가지치기로도 시간 내 탐색할 수 없는 문제

## 구현 포인트
#### 1. 종료 조건 설정
- 하나의 경우가 완성되는 시점을 명확히 지정
- 정답을 처리한 뒤 현재 재귀 호출을 종료

```java
if (depth == M) {
    // 정답 처리
    return;
}
```

#### 2. 선택 가능한 후보 탐색
- 현재 단계에서 선택할 수 있는 모든 후보를 반복

```java
for (int i = 0; i < N; i++) {
}
```

#### 3. 이미 선택한 값 확인
- 순열처럼 같은 값을 중복해서 선택할 수 없는 경우 방문 배열 사용

```java
if (visited[i]) continue;
```

#### 4. 가지치기
- 현재 후보를 선택했을 때 정답을 만들 수 없는 경우 재귀 호출을 하지 않음
- 가능한 한 이른 시점에 수행

```java
if (!isPossible(i)) continue;
```

#### 5. 상태 변경 후 재귀 호출
```java
visited[i] = true;
result[depth] = i;

backtracking(depth + 1);
```

#### 6. 상태 복원
- 현재 선택에 대한 탐색이 끝나면 선택 이전 상태로 복원
- 다른 경우의 수에서 같은 값을 다시 사용할 수 있게 함

```java
visited[i] = false;
```

## 시간복잡도
- 일반적인 시간복잡도를 정의할 수 없음
- 문제의 선택지 개수와 재귀 깊이에 따라 결정
- 대부분 최악의 경우 지수 시간(Exponential Time)
- 가지치기를 통해 실제 탐색량을 줄일 수 있음
- 최악의 경우에는 모든 경우를 탐색해야 함
- 입력 크기를 보고 완전탐색이 가능한지 먼저 판단해야 함

## 실수 포인트
- 재귀 호출 이후 상태를 복원하지 않음
```java
visited[i] = true;

backtracking(depth + 1);

visited[i] = false;
````

- 종료 조건을 잘못 설정 &rarr; N개의 후보 중 M개를 선택하는 문제라면 보통 depth == M
```java
if (depth == M) {
    return;
}
```

- 정답을 처리한 후 return하지 않음 &rarr; 배열 범위를 벗어나거나 불필요한 탐색이 이어질 수 있음
