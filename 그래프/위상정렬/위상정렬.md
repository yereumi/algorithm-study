# 위상정렬 (Topological Sort)

## 개념
- **방향 그래프(DAG)** 에서 간선의 방향을 거스르지 않도록 정점을 나열하는 것

## 사용 상황
- 반드시 **사이클이 없는 방향 그래프(DAG)** 여야 함
- 사이클이 있으면 위상정렬 불가능
- 예시
  - 선수 과목 문제
  - 작업 순서 정하기
  - 빌드 순서 결정
  - 선후 관계가 있는 스케줄링


## 구현 포인트
### 1) BFS 기반 (Kahn’s Algorithm)
- **진입차수(indegree)가 0인 정접부터 시작**
- 하나씩 제거하면서 순서 생성

#### 1. 진입차수 배열 생성
```java
int[] indegree = new int[V + 1];
```
#### 2. 간선 입력 시 indegree 증가
```java
graph[u].add(v);
indegree[v]++;
```

#### 3. indegree == 0 인 정점을 큐에 삽입
```java
Queue<Integer> q = new LinkedList<>();

for (int i = 1; i <= V; i++) {
    if (indegree[i] == 0) q.offer(i);
}
```

#### 4. BFS 진행
```java
while (!q.isEmpty()) {
    int cur = q.poll();
    result.add(cur);

    for (int next : graph.get(cur)) {
        indegree[next]--;
        if (indegree[next] == 0) {
            q.offer(next);
        }
    }
}
```

#### 5. 사이클 판별
```java
if (result.size() != V) {
    // 사이클 존재
}
```

### 2) DFS 기반
- DFS 후 스택에 넣기
- 재귀 종료 시점에 push

```java
void dfs(int cur) {
    visited[cur] = true;

    for (int next : graph.get(cur)) {
        if (!visited[next]) dfs(next);
    }

    stack.push(cur);
}
```

## 시간복잡도
- BFS 기반: **O(V + E)**
- DFS 기반 
  - 인접 리스트: **O(V + E)**
  - 인접 행렬: **O(V^2)**

## 실수 포인트
- 진입차수 업데이트 안함
- 진입차수가 0이 된 순간 바로 큐에 안 넣음
- 사이클 판별 안 함
- 그래프 방향 헷갈림
- DFS 위상정렬에서 방문 처리 실수
- 연결 그래프 아닐 때 한 번만 DFS
