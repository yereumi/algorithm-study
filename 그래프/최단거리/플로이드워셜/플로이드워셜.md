# 플로이드워셜 (Floyd–Warshall)

## 개념
- 모든 정점 쌍 (All-Pairs) 최단 거리를 구하는 알고리즘
- 음수 간선 허용
- 음수 사이클 판별 가능

## 사용 상황
- 모든 정점 간 최단 거리가 필요할 때
- 정점 수가 작을 때 (V ≤ 400 정도)
- 음수 간선이 있을 수 있을 때

- ❌ 사용 불가
  - 정점이 수천~수만 이상 (시간 초과)
  - 단일 시작점 최단 경로 (다익스트라가 더 효율적)

## 구현 포인트
#### 1. 거리 배열 초기화
- dist[i][i] = 0
- 나머지는 INF
- 간선 입력 시 최소값으로 갱신

```java
for (int i = 1; i <= V; i++) {
    for (int j = 1; j <= V; j++) {
        if (i == j) dist[i][j] = 0;
        else dist[i][j] = INF;
    }
}
```

#### 2. 3중 반복문 구조 (k가 가장 바깥)
```java
for (int k = 1; k <= V; k++) {
    for (int i = 1; i <= V; i++) {
        for (int j = 1; j <= V; j++) {
            if (dist[i][k] != INF && dist[k][j] != INF) {
                dist[i][j] = Math.min(
                    dist[i][j],
                    dist[i][k] + dist[k][j]
                );
            }
        }
    }
}
```

- 반드시 **k &rarr; i &rarr; j** 순서

#### 3. 점화식
```java
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

- i → j 직접 가는 것보다 i → k → j가 더 짧으면 갱신

#### 4. 음수 사이클 판별
```java
for (int i = 1; i <= V; i++) {
    if (dist[i][i] < 0) {
        // 음수 사이클 존재
    }
}
```

## 시간복잡도
- **O(V³)**

## 실수 포인트
- k를 가장 바깥 루프로 두지 않음
- INF + INF 연산으로 overflow 발생
- dist[i][i] = 0 초기화 안 함
- 간선 중복 입력 시 최소값 처리 안 함
- 1-index / 0-index 혼동
